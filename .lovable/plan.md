# 가입 온보딩 · 트레이너 연결 개선

## 1. 관리자(트레이너) 가입요청 카드에 실명 표시

현재 가입요청 카드는 "이미 연결된 회원 목록"에서 이름을 찾기 때문에, 아직 연결되지 않은 신청자는 항상 "회원"으로만 보입니다. (DB 접근 규칙상 트레이너는 자기 회원의 프로필만 읽을 수 있어, 신청자 프로필이 조회되지 않습니다.)

- 트레이너에게 온 **대기 중 가입요청 + 신청자 프로필**을 함께 돌려주는 전용 조회 함수를 추가합니다(트레이너 본인에게 온 요청만).
- 카드에 프로필 사진, 실명, 전화번호, 운동목표, 요청일을 표시. 이름이 비어 있을 때만 "이름 미입력".
- 신청자 사진도 보이도록, 대기 요청이 있는 동안만 해당 회원 사진을 트레이너가 볼 수 있게 저장소 접근 규칙을 좁게 추가.
- 승인/거절 처리 로직은 그대로 유지.

## 2. 시작 설문에서 트레이너 목록/검색 제거

- 설문 화면의 "트레이너 찾기" 목록·검색을 완전히 제거합니다.
- 연결 단계는 **초대코드 입력란 + `초대코드로 연결하기` + `나중에 연결하기`** 만 남깁니다.
- 코드 입력 전에는 어떤 트레이너 정보도 표시하지 않습니다. 유효한 코드를 넣으면 먼저 **대상 트레이너 이름만** 확인 화면에 보여주고, `연결하기`를 눌렀을 때 실제로 연결됩니다(검증·연결 모두 서버에서 수행).
- 오류는 친절한 한국어 문구로: 코드가 올바르지 않음 / 이미 다른 트레이너와 연결됨 / 본인 코드 사용 불가.
- `나중에 연결하기` → 설문 저장 후 회원 홈으로 이동.
- 이름이 비어 있으면 저장·연결 전에 이름 입력을 요구합니다.

참고: 초대코드는 지금도 트레이너별 1개(재발급 가능)이며 기간 만료 개념은 없습니다. 이미 연결된 회원의 재사용은 서버에서 차단되므로 "이미 사용됨" 케이스는 이 규칙으로 안내합니다.

## 3. 회원 홈 · 트레이너 연결 화면

- 미연결 회원 홈 상단에 안내 카드: "아직 연결된 트레이너가 없어요. 초대코드를 입력하거나 트레이너를 찾아 연결을 요청해 보세요." + `초대코드 입력` / `트레이너 찾기` 버튼. 연결된 회원에게는 표시하지 않습니다.
- 새 화면 `/connect` (초대코드 / 트레이너 찾기 두 영역):
  - 검색은 **2글자 이상 입력 시에만** 결과를 표시(전체 목록 노출 금지), 결과는 이름 + "퍼스널 트레이너" 정도의 최소 정보만.
  - `연결 요청` 전송 → 같은 트레이너에게 중복 요청 차단, `승인 대기 중` 배지 표시, `요청 취소` 가능.
  - 승인되면 담당 트레이너 관계 생성(기존 동작 유지), 거절 시 "거절되었어요" 상태 안내.
- 미연결 상태에서 예약(`/book`), 이용권(`/pass`), 운동기록(`/records`)은 오류/빈 화면 대신 연결 안내 화면 + `/connect` 버튼을 보여줍니다.

## 4. 권한

- 가입요청은 로그인한 회원의 실제 프로필 ID로만 생성(회원은 자기 요청만 조회/생성/취소).
- 트레이너는 자신에게 온 요청만 조회/승인/거절. 타 트레이너·타 회원 정보 접근 불가.
- 트레이너 검색은 이름만 반환하는 전용 함수로 처리(연락처·부상이력 등 노출 없음).

## 5. 데이터 보존

기존 회원·예약·운동기록·PT 이력은 그대로 유지합니다. 마이그레이션은 추가만 수행합니다(조회 함수, 중복 요청 방지 인덱스, 좁은 사진 열람 규칙).

## 기술 메모

- 마이그레이션: `pending_join_requests()`, `search_trainers(_term text)`(2자 미만은 빈 결과), `preview_invite_code(_code text)`(연결 없이 트레이너명만) 보안 함수 추가 + `authenticated` 에만 EXECUTE 부여; `join_requests`에 (member_id, trainer_id) 대기중 중복 방지 부분 유니크 인덱스; `storage.objects` SELECT 정책 1개 추가(대기 요청 신청자 사진).
- 코드 변경: `src/routes/_authenticated/onboarding.tsx`(목록 제거·코드 2단계 확인), 신규 `src/routes/_authenticated/connect.tsx`, `src/routes/_authenticated/home.tsx`(안내 카드), `src/routes/_authenticated/trainer/home.tsx`(요청 카드 실명/프로필), `book.tsx`·`pass.tsx`·`records.tsx`(미연결 안내), 공용 안내 컴포넌트는 `src/components/pt/kit.tsx` 패턴 재사용.
- 디자인은 기존 크림/블랙/라임 토큰과 rounded-2xl, 모바일 우선 레이아웃 유지. 마무리로 타입체크·린트·빌드 및 브라우저 플로우 점검.
